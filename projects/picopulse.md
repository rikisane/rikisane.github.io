After playing video games for most of my life, Wi-Fi-related issues have always been a frustrating problem for me. Because of this, I decided to create the Pico Pulse, a small device designed to help me visually monitor what is happening with my internet connection in real time.

The device uses an OLED screen and a joystick connected to a breadboard to display important network information. For example, it can show a live graph of Wi-Fi connectivity, perform ping tests, and handle connection errors through automatic reconnection features. By programming the device with MicroPython, I was able to combine multiple libraries and files into a single program that brings all of these features together. Through this project, I turned a problem I regularly experienced while gaming into a practical tool for monitoring and troubleshooting network connectivity.
